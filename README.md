# Simple Modular Calculator

## Project Overview

This project is a simple calculator made using Python.
It performs basic mathematical operations such as addition,
subtraction, multiplication and division.

The project uses separate Python files for each operation.as we are given conditions

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Invalid input handling
- Multiple calculations

## Technologies Used
  jupyter             
- Python
- Jupyter Notebook
- Git and GitHub

## Project Files

- addition.py - Addition function
- subtraction.py - Subtraction function
- multiplication.py - Multiplication function
- division.py - Division function
- new_calculator.py - Main calculator program
- calculator_project_vityarthi.ipynb - Jupyter Notebook

## How to Run

1. Open the project folder.
2. Open the Jupyter Notebook.
3. Run the calculator program.
4. Enter two numbers.
5. Select an operation.
6. View the result.

## Testing
